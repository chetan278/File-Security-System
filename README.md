# File Security System — Aegis

Aegis is a Python-based file security application that combines database management, operating-system concepts, and security controls to protect files and monitor access. It includes a Flask web interface and a SQLite database for storing users, file metadata, permissions, and audit events.

## Features

- **User authentication:** Password verification using bcrypt.
- **Role-based access control (RBAC):** Separate administrator and employee roles.
- **File permissions:** Store and check file-reading permissions for users.
- **Account lockout:** Lock accounts after repeated failed login attempts.
- **File integrity checking:** Calculate SHA-256 hashes to help detect file changes.
- **Audit logging:** Record access attempts and security-related actions.
- **Protected file handling:** Support for common document, spreadsheet, presentation, and image formats.
- **Operating-system demonstrations:** Process information, OS file-permission checks, file locking, and controlled concurrent reads.
- **Database demonstrations:** SQLite tables, transaction/recovery-related examples, permission management, analytics, and query optimization.
- **Web interface:** Flask-powered login and security dashboard pages.

## Technology Stack

- Python
- Flask
- SQLite
- bcrypt
- HTML and CSS
- Python standard libraries for hashing, file handling, concurrency, and system inspection
- `psutil` (optional, for additional process and memory information)

## Requirements

Python 3.10 or later is recommended.

Install the main dependencies:

```bash
pip install Flask bcrypt
```

Optional dependency for detailed process and memory information:

```bash
pip install psutil
```

## Setup and Run

1. Download or clone the repository:

   ```bash
   git clone https://github.com/chetan278/File-Security-System.git
   cd File-Security-System
   ```

2. Create and activate a virtual environment (recommended):

   **Windows**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

   **macOS/Linux**
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```

3. Install dependencies:

   ```bash
   pip install Flask bcrypt psutil
   ```

4. Ensure the security module is named `module3_security.py`, as described above.

5. Start the web application:

   ```bash
   python app.py
   ```

   If the application is configured to start through `main.py` in your version, run:

   ```bash
   python main.py
   ```

6. Open the local address printed by Flask in your browser (commonly `http://127.0.0.1:5000`).

## Database Overview

The SQLite database is named `security_system.db`. Depending on the modules enabled, it stores information such as:

- `users` — usernames, password hashes, roles, and account-lock status
- `files` — registered file names, paths, and sizes
- `permissions` — user-to-file read permissions
- `audit_logs` — security events and access decisions

The database is generated by the application; it generally should not need to be created manually.

## Security Notes

This repository is a learning/demo project, not a production-ready security product. Before deploying it publicly:

- Move all secrets, SMTP credentials, and peppers into environment variables and rotate any credentials that have been committed.
- Replace the hard-coded Flask secret key with a securely generated environment variable.
- Do not expose sample accounts or demo passwords in a public deployment.
- Configure secure session cookies and HTTPS for production.
- Validate file uploads and enforce authorization on every file operation.
- Review password-reset and email-delivery flows before using real accounts.
- Avoid deleting the database automatically on application startup if persistent data is required.
